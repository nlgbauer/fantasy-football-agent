# Security policy

This portfolio edition contains fictional data only. Do not report secrets through public issues.

Never commit `.env`, ESPN session values, email credentials, WhatsApp sessions, member identifiers, private stories, photographs, generated newsletters, SQLite databases, or provider receipts. The repository ignores the expected local paths, but contributors must review staged changes before every push.

The ESPN lineup writer is intentionally restricted to starter/bench `LINEUP` items. Changes involving acquisitions, drops, waivers, bids, trades, or IR must remain outside the automatic write boundary.

For a suspected vulnerability, contact the repository owner privately through the contact method listed on their GitHub profile.
